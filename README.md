# Isles of Ink

How manga, manhwa and manhua changed from 2014 to today, and what that says about readers.

This is the public copy of a **Microsoft Fabric App**. It runs the same page as the app inside Fabric, but reads a
snapshot of the semantic model's query results (`snapshot.json`, exported 2026-10-02)
instead of querying Fabric live.

- Readers: AniList list additions, March 2018 to September 2026, on a post-stratified panel of over 4,000 works.
- Works: the MangaDex catalogue, about 43,000 titles.
- Cover images © their publishers, via AniList.
- Third-party code notices: `THIRD_PARTY_NOTICES.txt`.
